# Наталья · Перманентный макияж — исходники для Cursor

Экспорт последней опубликованной **версии 13** от 15 ноября 2026 года.
Исходный коммит: `f6fdf1d7535c5809ff5581f20ce633936937dadd`.

Сайт при экспорте не изменялся и повторно не публиковался. Все файлы исходного коммита сохранены побайтно. Дополнительно включены этот README, локальный сервер, задача Cursor и отчёт проверки.

## Быстрый запуск в Windows

1. Распакуйте ZIP целиком. Откройте папку `natalia-site-v13` через **File → Open Folder** в Cursor. Именно в ней находятся `README.md`, `serve.py` и `dist`.
2. Нужен установленный **Python 3.9 или новее**. Проверьте в терминале Cursor:

   ```powershell
   py -3 --version
   ```

3. В этом же терминале, из корня открытого проекта, выполните:

   ```powershell
   py -3 serve.py
   ```

4. Откройте в браузере **http://127.0.0.1:4173/**.
5. Для остановки нажмите **Ctrl+C** в терминале.

Если команда `py` не найдена, но Python установлен и доступен как `python`, используйте `python --version` и `python serve.py`. Если не найдены обе команды, установите Python 3 с python.org и перезапустите Cursor.

## macOS / Linux

В терминале Cursor, из корня проекта:

```bash
python3 --version
python3 serve.py
```

Откройте **http://127.0.0.1:4173/**. Остановка — **Ctrl+C**.

## Если порт занят

Windows:

```powershell
py -3 serve.py --port 4174
```

macOS / Linux:

```bash
python3 serve.py --port 4174
```

Адрес в таком случае: **http://127.0.0.1:4174/**.

## Запуск задачей Cursor

После открытия корневой папки выберите **Terminal → Run Task → Запустить сайт Натальи**. Задача использует `py -3` на Windows и `python3` на macOS/Linux. Если на вашем Windows доступна только команда `python`, запускайте её вручную либо укажите её в Windows-настройке `.vscode/tasks.json`.

Можно использовать и стандартный сервер Python без `serve.py`:

```powershell
py -3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

На macOS/Linux замените начало команды `py -3` на `python3`.

## Что находится внутри

| Путь | Назначение |
| --- | --- |
| `dist/index.html` | Весь текущий сайт: HTML, встроенные CSS и JavaScript, данные работ, фильтры, просмотр фото, подбор услуги и меню |
| `dist/assets/` | Все изображения и шрифты, включая исходные фото работ и иллюстративные обложки; сохранены и ранее использованные файлы |
| `dist/previous.html` | Прежний вариант, сохранённый в опубликованных исходниках |
| `dist/compare.html` | Сравнение прежней и текущей версии |
| `dist/mobile.html` | Встроенный просмотр на мобильной ширине |
| `.openai/hosting.json` | Оригинальная конфигурация Sites с существующим идентификатором проекта |
| `.vscode/tasks.json` | Локальная задача запуска для Cursor |
| `serve.py` | Сервер только на 127.0.0.1; ничего не загружает и не публикует |
| `EXPORT_INFO.json` | Версия, коммит и результаты проверки локальных ресурсов |
| `SOURCE_SHA256SUMS.txt` | Контрольные суммы всех файлов исходного опубликованного коммита |

### Где редактировать

Основной файл — `dist/index.html`. Стили находятся в его блоках `<style>`, поведение — в `<script>`. Отдельных `styles.css` и `app.js` в исходной версии нет: код не пропущен, он встроен в HTML. После изменения сохраните файл и обновите страницу браузера. Автоматической пересборки или live reload нет.

Не требуется `npm install`, Node.js, сборщик, API-ключи, `.env` или база данных. Серверная часть записи отсутствует: кнопка ведёт в VK. Локальные правки не меняют опубликованный сайт.

- Брови: http://127.0.0.1:4173/?works=brows#portfolio
- Губы: http://127.0.0.1:4173/?works=lips#portfolio
- Межресничка: http://127.0.0.1:4173/?works=eyes#portfolio
- Сравнение версий: http://127.0.0.1:4173/compare.html
- Мобильный просмотр: http://127.0.0.1:4173/mobile.html

Запускайте сайт по HTTP, как указано выше, а не двойным щелчком по HTML: относительные ссылки, параметры галерей и локальные шрифты рассчитаны на обычный веб-сервер. Не переносите `index.html` отдельно от папки `assets`.

## Независимость от временных ссылок

Все постоянные изображения и шрифты включены в ZIP и подключены относительными путями. Ссылок на временные файлы ChatGPT, облачные подписанные URL, CDN-шрифты или внешние JS-пакеты в исходниках нет. Оформление, галереи и локальный подбор направления работают без интернет-подключения после запуска сервера.

Единственный внешний переход в страницах — `https://vk.ru/hanimeypermanent`, для него нужен интернет. Это ссылка записи, а не зависимость оформления. В режиме согласования загрузка своих файлов создаёт временные `blob:`-адреса непосредственно в браузере; они нужны только для необязательного локального просмотра и исчезают после обновления страницы. Они не используются для штатных фотографий сайта.

## Границы экспорта

Это полный статический исходный проект опубликованной версии, а не новый проект на React/Vite. Репозиторий `.git`, ключи, токены, история переписки и временные файлы среды не включены. Развёртывание и права доступа Sites управляются отдельно и не нужны для локальной работы. Не считайте наличие `.openai/hosting.json` автоматической настройкой публикации из Cursor: обычный запуск ничего не публикует.
